Pill-shaped action with uppercase extrabold label; use primary for the one main action per screen.

```jsx
<Button variant="primary" size="lg" block>Get started</Button>
<Button variant="secondary" size="lg" block>Log in</Button>
```

- Labels are ink on orange (never white — white on #F29A1E fails contrast).
- Pair primary + secondary stacked on onboarding; single primary at the bottom of detail screens ("Let's go eat").
