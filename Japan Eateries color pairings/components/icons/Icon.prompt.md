Lucide icon rendered as a CSS mask so it takes any color; use for every glyph in the app.

```jsx
<Icon name="map-pin" size={16} color="var(--accent)" />
```

- `name` is any Lucide name (search, heart, bell, home, bookmark, receipt, user, chevron-left, star, clock).
- Sizes in use: 14 (inline meta), 16–18 (chips, nav), 20–22 (icon buttons).
