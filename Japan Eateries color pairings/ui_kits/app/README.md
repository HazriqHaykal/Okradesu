# Japan Eateries — mobile app UI kit

Click-through recreation of the three screens in the reference shot (`uploads/pasted-1790341427040-0.png`), re-skinned in direction 1b.

- `Frame.jsx` — phone shell, food-render placeholder, sample data
- `Welcome.jsx` — onboarding: food collage, display headline, Get started / Log in
- `Home.jsx` — location, title + local time, search, Browse by Food, Recommendation grid, floating tab bar
- `Detail.jsx` — dish render, facts row, description, visitors, "Let's go eat"

Flow: Get started → Home → tap a card → Detail → back. Hearts toggle; category tiles select; tab bar switches.
Food renders are striped placeholders — drop in transparent PNG renders.
